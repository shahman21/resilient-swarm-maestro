Leap + mBot2 + 网页同机同步

本包基于你已经跑通的 30 度倾斜控制，并使用团队 GitHub main 的最新 dashboard 页面。
UI 和 main 的 index.html 在读取时一致：a6aec37e5325a42882b87dca94d346ae2ebfdd13。
保留团队界面、音乐、群体视觉和 3D 装饰；增加 USB 指令同步及估算俯视轨迹。
未修改 GitHub 仓库，未连接云数据库或 API。

一、你要保留的东西
1. 小车、Leap Motion 2 分别 USB 连接同一台 Windows 电脑。
2. 底盘电源打开，Ultraleap Tracking 正常运行。
3. mBlock 保持“在线”并连接童芯派。
4. 已测试成功的四组积木保持不变：
   W → 前进 30 RPM → 等待 0.2 秒 → 停止全部编码电机。
   A → 左转 30 RPM → 等待 0.2 秒 → 停止全部编码电机。
   D → 右转 30 RPM → 等待 0.2 秒 → 停止全部编码电机。
   空格 → 停止全部编码电机。

二、启动
1. 如果旧 Leap Python 程序还在运行，在它的黑色窗口按 Ctrl+C 停止。
2. 将整个 ZIP 解压到一个普通文件夹。不要在 ZIP 压缩包里直接运行。
3. 双击 START_WINDOWS.bat。程序使用你已经安装的 Python，不需要 pip 安装。
4. 程序会自动打开浏览器：
   http://127.0.0.1:8765
   如果没有自动打开，手动复制这个地址。不要打开旧的 localhost:8000 页面，也不要直接双击 index.html。
5. 首次保持轮子架空，验证前进、左右转和停车。地面演示时留足空间，照看 USB 线。

三、同时显示网页和控制小车
1. 将浏览器放在屏幕左半边，mBlock 放在右半边。可以用 Windows+左方向键/右方向键排列窗口。
2. 网页的“Start Audio”、Globe View、配色、密度等视觉按钮可以先设置。
3. 最后一定要点击 mBlock 积木区空白处，让 mBlock 成为当前活动窗口。
4. 手掌朝下、水平保持约半秒，完成校准。
5. 水平 → W 前进；左边压低超过约 30° → A 左转；右边压低超过约 30° → D 右转。
6. 回正到约 15° 内 → 恢复前进；握拳或移开手 → 发送空格停车。
7. 网页同步显示当前发送指令、手势、角度和估算轨迹。无需点击网页，它会自行刷新。
8. 点击浏览器或聊天窗口后，程序停止向小车发送新运动键。回到 mBlock 并点击空白处，再平放手掌重新校准即可。
9. ESC 或黑色窗口中的 Ctrl+C 可退出桥接程序。小车底盘电源用于必要时直接停车。

四、同步的含义
- 同一个 Python 进程读取 Leap，只识别一次手势。
- 它给 mBlock 发送 W/A/D/空格，同时把已发送按键和估算位置提供给网页。
- 本机网页数据采用约 60 ms 间隔轮询，动画还有平滑，因此不承诺零延迟。
- 网页位置根据 30 RPM、0.2 秒动作和估计轮径/轮距计算，不是机器人实测位置。
- 车轮打滑、电量、地面和实际串口延迟会造成实体与图像位置误差。
- “USB bridge live”表示 Leap 控制进程活跃，不是小车位置回传，也不能证明 mBlock 实际收到了每一条命令。
- 队友原来的音乐节奏、背景装饰及统计图是演示视觉；USB 同步条和命令估算轨迹属于当前控制数据。
- 网络故障和旧舞蹈规则按钮在 USB 模式下禁用，避免误以为它们能控制实体车。
- 网页不再开启第二个摄像头做手势识别；3D 装饰角度来自同一份 Leap 数据。

五、常见问题
- 黑色窗口报端口被占用：先关闭旧同步程序，或在本文件夹的命令窗口运行：
  py leap_sync.py --port 8766
  然后打开 http://127.0.0.1:8766 。
- 默认 Leap DLL 路径已经按你电脑设置：
  D:\leap motion\Ultraleap\LeapSDK\lib\x64\LeapC.dll
- 如果左右相反，可运行：
  py leap_sync.py --invert-roll
- 页面开着但小车不动：先点击 mBlock 空白处，再手动按 W，确认在线连接仍有效。
- 网页显示“Waiting for Leap bridge”：确认启动的是 leap_sync.py，而不是旧的 leap_to_mblock_tilt30.py。
- 已打包主要 2D/3D 依赖；Google 字体加载失败时使用系统字体。
- 如果你修改了 mBlock 速度或等待时间，local_sync.py 中的轨迹估计参数也要相应修改。

dashboard/index.html：团队网页，增加 USB 同步接入。

dashboard/swarm-lattice.mjs：团队 3D 视觉，增加同一 Leap 角度输入。
dashboard/vendor：随包附带的主要视觉依赖与许可说明。
